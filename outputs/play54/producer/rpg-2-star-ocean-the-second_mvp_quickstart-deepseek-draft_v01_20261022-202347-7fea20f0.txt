## 1) 安装与启动 / Setup & Launch
完整解压 ZIP，并保持所有文件在同一目录；双击以项目名命名的启动 `.cmd`。内置 Godot 运行时和 PCK，无需安装编辑器。主菜单选择语言 → New Game → 输入姓名 → 选择 male/female。
Extract the full ZIP and keep all files together; double-click the project-named start `.cmd`. The bundled Godot runtime and PCK require no editor installation. Main menu: choose language → New Game → enter name → male/female.

本包是开发者 runtime+PCK，不是原生发行 EXE，也不证明最终美术或限时真人试玩。
This is a developer runtime+PCK bundle, not a native release EXE, and not proof of final art or timed human plays.

## 2) 操作、存档与反馈 / Controls, Saves & Reporting
探索：WASD 移动，E 交互，Esc 地图/返回。战斗：A/D 移动，J 攻击，K 闪避，L 防御，Q 个人，R 职业，Tab 切换，P 暂停，T 自动。
Exploration: WASD move, E interact, Esc map/back. Battle: A/D move, J attack, K dodge, L guard, Q personal, R job, Tab switch, P pause, T auto.

用界面可见的 Save 按钮存档；存档保存在 Windows `%APPDATA%\Godot\app_userdata\Worlds Between` 下，具体子文件夹未确认。
Save via the visible Save button; saves persist under `%APPDATA%\Godot\app_userdata\Worlds Between`; the exact subfolder is not confirmed.

三名可招募同伴：LiangXu、ZhaoLing、JiCheng；无跟随者。MVP 默认为 heroine/male、三名同伴、NYC CityHallPark、Washington exterior+records、Chicago 与 sentry/patrol。最终美术/动作未完成，打磨延后。
Recruitable companions: LiangXu, ZhaoLing, JiCheng; no followers. MVP defaults: heroine/male, three companions, NYC CityHallPark, Washington exterior+records, Chicago, and sentry/patrol. Final art/motion are incomplete; polish is deferred.
