Worlds Between — 开发试玩版 / Developer playtest

启动
1. 完整解压 ZIP。保持文件在同一个文件夹，不要在压缩包内启动。
2. 双击文件名含 playtest-launcher_normal 的 .cmd 文件。
3. 主菜单切换语言，选择“新游戏”，输入姓名并选择男主或女主，然后出发。
无需安装 Godot 编辑器。请勿单独双击 Godot 引擎文件；使用启动器。

怎么玩
探索：WASD 移动，E 调查/交谈，Esc 返回地图。
战斗：A/D 移动；J 攻击；K 闪避；按住 L 防御；Q 个人技能；R 职业技能；
Tab 切换操纵角色；P 暂停下指令；T 切换全自动。设置中可切换方向键移动。
按当前调查目标推进纽约、扬克斯和华盛顿的调查，再返回纽约汇报。
同伴梁序、赵铃、纪澄可招募并参与战斗；探索时不会作为跟随队伍出现。
地图及管理界面提供存档入口。主菜单“读取”可继续；不要覆盖想保留的旧存档槽。
默认存档位于 %APPDATA%\Godot\app_userdata\Worlds Between 下，关闭游戏仍保留。

本包使用已授权的 MVP 默认角色、场景及敌人显示。人物与场景精修后置。
这是自带引擎和游戏数据的开发试玩包；不是正式发行版，不代表最终美术验收或真人试玩通过。
遇到问题请记录：语言、操作步骤、预期结果、实际结果与截图。
需要诊断时可用文件名含 playtest-launcher_console-log 的 .cmd 启动，保留控制台报错。

Launch
1. Extract the entire ZIP; keep its files together. Do not launch from inside the ZIP.
2. Double-click the .cmd file whose name contains playtest-launcher_normal.
3. Select a language on the main menu, choose New Game, enter a name, choose male or female, and depart.
No Godot editor installation is required. Use the launcher rather than opening the engine executable directly.

Play
Explore: WASD move, E investigate/talk, Esc return to the map.
Battle: A/D move; J attack; K dodge; hold L to guard; Q personal skill; R job skill;
Tab switch character; P pause for commands; T toggle full auto. Settings offer arrow-key movement.
Follow the current objectives through NYC, Yonkers and Washington, then return to NYC to report.
Liang Xu, Zhao Ling and Ji Cheng can be recruited and fight with you; there are no persistent exploration followers.
Use the Save entry in the map/management screens; use Load on the main menu to resume.
Avoid overwriting existing slots you want to keep. Saves persist under
%APPDATA%\Godot\app_userdata\Worlds Between after the game closes.

This bundle uses the creator-authorized MVP default characters, environments and enemies. Polish is deferred.
It is a developer playtest bundle containing the engine and game data, not a native release export,
final art approval, or completion of a required human playthrough.
Report problems with language, steps, expected result, actual result and a screenshot.
For diagnostics, launch the .cmd containing playtest-launcher_console-log and retain any console errors.
