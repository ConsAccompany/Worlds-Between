# 全球地图路线卡可读性修正（M2）

状态：**小修正已完成，自动检查与 1280×720 实机截图检查通过；M2 全球地图与旅行仍未最终验收**。地图美术未验收，未经真人试玩。核验日期：2026-10-15。

## 问题

地区层打开路线卡时，卡片背景透明度为 0.96，底下的地图会透出来：经纬线、度数标签（如 “123°E”、“31°N”）和海岸线隐约可见，与卡片文字叠在一起。另外，“122°E” 一类标签只有一半被卡片左缘盖住，看起来像被切断的 “1”。

修正前截图（存于临时目录，未入库）可以看到以上两点。

## 修正（只改 `game/scripts/scifi_world_map.gd`）

1. 路线卡背景改为不透明（`bg_color` 透明度 0.96 → 1.0），颜色不变，地图不再透出。
2. 新增 `annotation_label_rects()`，地区层的度数标签和参照地名标签都由它统一排版，并供测试读取。路线卡打开时：
   - 纬度标签（如 31°N、30°N）移到卡片左缘外侧右对齐，打开路线卡时纬度刻度仍然可读；
   - 会碰到卡片的标签（例如 122°E、123°E，或缩放后落在卡片下的参照地名）这一帧不画，不再出现被切掉一半的文字；
   - 路线卡关闭后，标签位置与修正前相同。
3. 没有改动：路线登记表、游戏数据、Game Bible、路线 API 调用、预览／确认／取消流程、标记坐标、全球层与地区层布局、中英文文案。

## 测试

新增 `game/tests/rpg-2-star-ocean-the-second_global-map-route-card_readability-check_m2-v01_20261015-033343-e51bfe23.gd`（需显示渲染器，不加 `--headless`）。中英文各检查 5 个卡片画面：良渚、松江、上海（所在地）、放大 1.5 倍后的良渚，以及无路线 API 的良渚。每个画面检查：

- 卡片高度不超过 238 px（不被内容撑高）；
- 所有标注标签都不与卡片相交；
- 打开卡片时纬度标签数量与关闭时相同（移位，不删除）；
- **像素比对**：同一画面渲染两次，一次正常，一次隐藏整个地图层，卡片范围内（1280×720 下）的像素必须完全相同，也就是地图上的任何东西都不会透到卡片里。

修正前运行：55 项中 35 项失败，每张卡有 13 万至 17 万像素受底图影响。修正后：**99 项全部通过**（`ROUTE_CARD_READABILITY_OK 99 checks`）。
