## Renderer and local server

- **App (`outputs/…game-bible_app_v01…js`):**

  - Any other type, path, kind or pin renders as text. Without `currentCandidates`, the old flat PNG layout is used.
- **Server v05:**
  - Four exact nested PNG entries were added to the allowlist.
  - A new `/media/<exact name>` route serves only the 2 pinned MP4s:
    - each must be ≤16 MiB (413 otherwise);
    - sha256 is verified on every request (409 on mismatch);
    - the response is `video/mp4` with `Accept-Ranges: bytes`;
    - single and suffix ranges return 206, and malformed or multi-range requests return 416;
    - every other path returns 404.
  - `mediaResponse` is exported for the test, and the server only listens when run directly.
