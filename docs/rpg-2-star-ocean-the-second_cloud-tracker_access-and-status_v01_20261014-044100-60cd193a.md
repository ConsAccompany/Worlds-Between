# Worlds Between cloud project tracker

Published tracker: https://worlds-between-tracker.kel949649.chatgpt.site

Sign in using the owner's ChatGPT account on any machine. This is a hosted private Site; it does not depend on the original PC or localhost server being online.

The tracker preserves the original game bible's world, confirmed rules, character profiles, job proposals, milestones, categorized assets and visual-quality gates. Project baseline data is fetched from ConsAccompany/Worlds-Between main, pinned to a commit for each refresh. If GitHub is temporarily unavailable, the tracker labels its last verified snapshot. All 51 profiles, 52 visual variants and 11 technology-region scene gates remain in scope.

Cloud records: two playtest feedback fields, purpose-specific asset review marks and imported M7 completion receipts persist in the signed-in account's cloud database. Review marks do not automatically change the GitHub inventory; export cloud records from the Production page and reconcile them into repository records. Old browser-local notes must be copied manually.

Receipts are checked for the M7 completion schema. The uploader explicitly declares whether a receipt comes from a human playthrough; automated and unreviewed evidence remain labeled, and uploads never complete a milestone automatically. This Site cannot launch the native Godot game. Run Godot locally, finish the city report, then import its completion JSON.
