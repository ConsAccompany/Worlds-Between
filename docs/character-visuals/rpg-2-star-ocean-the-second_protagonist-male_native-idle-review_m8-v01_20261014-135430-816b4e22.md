- 参考既有 21:9 男主角设定图：短而蓬乱的深棕黑发，向左右不对称伸出的发束；茶绿围巾；褐色翻领长外套；茶绿卷起的睡袋、背包和菱形徽记。

- 人物独有视觉线索优先级：发型外轮廓、茶绿围巾／睡袋、褐色探索外套。细小面部表情只是辅助。

## 原生像素与场景检验

- 四张最终 PNG 各为透明 RGBA **32×48**，直接在目标像素格上绘制；没有把概念图或前一轮高分辨率裁切图缩小。可见包围盒最上缘 `y=3`、最下缘 `y=44`，可见高度 **42 px**；固定脚底锚点 `(16,44)`。
- 每帧含透明色共有 18–27 个 RGBA 色值，满足首轮 20–32 色的建议量级。PNG 均未使用渐变、模糊、抗锯齿或缩放。
- 预览方法：读取既有科技城环境背景，作为 QA 场景缩至 640×360 逻辑画面；**32×48 角色像素在 `(320,239)` 足底坐标原样 1:1 叠放**。四个方向分别输出独立的 640×360 场景文件，未组成拼图。背景缩放不改变角色像素。
- 已人工查看四张 native PNG 和正、背两个场景预览。正面黑发轮廓、围巾与外套在暖色铺地上能分辨；背面睡袋和背包仍可辨。侧面在纯透明画布上可辨，正式 Godot 场景、移动时遮挡以及与女主角／梁序的无名字对照仍待复核。
