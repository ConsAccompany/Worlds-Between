# 角色四方向样板：首轮审查

**结论：退回原生像素重绘。** 首轮采用 21:9 来源画像生成了独立透明图，人物身份大体保留，但输出仍为 1000 像素以上的概念级单方向 cutout。以 Godot 4.7.2 在 640×360 的实际背景、40 像素角色高度渲染后，发型与服装关键特征大部分淹没于城市场景。不能计入“游戏内展示图”“标准四方向探索精灵”或 M8 美术验收。

## 来源核对

- 以现有资产清单的 `portrait.*` 顺序建立 **52 个稳定 visual ID**：主角男女两版＋编号 01–50 的伙伴。所有 52 张引用的 PNG 在仓库 `outputs/` 中存在。
- 来源画像批准状态原样保留：**9 approved、43 concept**。已获批准的九张是蒋岚、米洛、阿荻、娜丽娅、伊赛、达伽、晨弦、夜澜、洛纹的发型修订。主角男、主角女和梁序的来源画像仍是 concept；他们的本轮新图也没有获批准。
- 52-entry registry 可机器检查 ID 唯一、来源文件及方向草案文件存在。它不修改 Game Bible 或资产清单的完成状态。

## 发型重复风险与下一轮顺序

1. 主角男／女共享衣色和背包，优先保证女主马尾在南、北、侧面均超出头肩轮廓；男主发顶应是低而散的层次，不误长成高髻。
2. 梁序、叶乔、赫娅等盘发／盘辫角色要以**头部高度、发束位置和银色侧发块**分开。梁序不能只靠银色细线。
3. 科技区的林阙、赵铃、裴支、苏砚均有短发，分别保留蓝色碎层、耳机＋齐整侧分、红褐平头＋颈后面罩、剃短两侧＋顶部紫灰卷；去掉名字标签再测试。
4. 米洛与弥罗虽中文近音，前者极短圆寸及医袍，后者半长中分黑白发与左右异色书带。机器人以各异的环、叶、站牌、门拱、扁圆、棱柱、半月头形优先区分。
5. 先手工整理主角男、主角女、梁序的 **32×48 原生像素**四方向待机，再验证 40px 同屏辨识；过关后再做 4 帧行走与其余 49 个视觉版本。勿把首轮概念 cutout 直接批量复制到 52 人。

对应批次 manifest 在 `game/data/character-visuals/`；来源状态以已有资产清单为准。
