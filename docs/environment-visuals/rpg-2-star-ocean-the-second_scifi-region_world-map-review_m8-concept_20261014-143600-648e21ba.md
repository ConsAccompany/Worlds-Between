## 地理与生成简报

科技区是**同一星球**上一片连续地区。地图西侧是旧石街区与青绿色公共设施交织的滨水城市；中部转为林地、农田与低山中的中继站；东侧逐渐干燥，岩坡上保留旧文明遗址。河流、丘陵与海岸把三处连接为同一个自然地理空间；没有将板块画成独立浮岛。风格为高密度、清晰的二维像素地图插画，建筑与自然沿用科技城的暖石、青绿和黄铜色调。

生成约束：单张 16:9 连贯地形；城市视觉重心在左侧约 `(136,174)`，郊外林地在中部约 `(324,230)`，遗址在右侧约 `(510,150)`；为三个标记及下方按钮留较安静的颜色区域；不要画路线、图钉、地点圆圈、图例、文字、数字、UI、人物、徽标或水印。顶部约 62 像素和底部 y=313 之后会被游戏 UI 覆盖。
